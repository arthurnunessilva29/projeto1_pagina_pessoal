# Projeto 1 - Página Pessoal

Projeto desenvolvido individualmente por Arthur Nunes.

##Instruções para abrir

- Para abrir o projeto, baixe o repositório em "Code" e "Download ZIP";
- Descompacte o arquivo e abra a pasta no VSCode;
- Entre na pasta `projeto1_pagina_pessoal`;
- Abra o arquivo `index.html`;
- Com a extensão **Live Server** ativa, clique em **Go Live** no canto inferior direito para abrir a página.

## Páginas

A primeira página apresenta uma apresentação pessoal, informações sobre mim, meus interesses, estudos, mídia e contato.

A segunda página, acessada pela seção de interesses, apresenta meu interesse pela área de cibersegurança e o curso que estou realizando pela Cisco.

O projeto possui:

- Estrutura semântica;
- Duas páginas HTML;
- Links para navegação entre as páginas;
- Imagem de apresentação;
- Listas ordenadas e não ordenadas;
- Tabela de estudos;
- Áudio;
- Formulário de contato.

## Testes e uso de IA

Todos os links internos e os links de navegação entre as páginas foram testados.

A IA foi utilizada apenas para auxiliar na estilização do CSS.
